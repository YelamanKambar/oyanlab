# OyanLab — Landing Page Design Brief

## 1. Project Overview

Create a visually striking, unconventional landing page for **OyanLab**, a digital educational studio based in Kazakhstan.

OyanLab creates modern educational materials for school teachers, helping them make lessons more engaging, visual, and interactive.

The target audience includes teachers of ALL school subjects in Kazakhstan.

The primary goal is to introduce the brand, communicate its services, and encourage teachers to contact OyanLab.

This project consists of **two separate 3:4 visual pages**, designed as premium Instagram carousel-style promotional slides.

Do not create a conventional corporate website layout. Treat each page as a carefully art-directed visual composition.

## 2. Brand Identity

Brand name: **OyanLab**

Brand concept:
- "Oyan" is a Kazakh word meaning "Wake up" or "Awaken".
- "Lab" represents experimentation, creativity, and technology.
- The brand represents awakening curiosity and making education more engaging through digital tools.

Brand personality:
- Modern
- Technological
- Creative
- Confident
- Innovative
- Professional, but not overly formal

The design should feel like a combination of a contemporary technology startup, a creative digital studio, and an experimental educational platform.

## 3. Color Palette

Use the following brand colors consistently:

| Color | Hex | Purpose |
|---|---|---|
| Deep Navy | #0B1530 | Primary background |
| Electric Blue | #13B8F5 | Highlights and accents |
| Vivid Purple | #8546F5 | Gradients and visual accents |
| Soft White | #F5F7FC | Main text and light surfaces |

Additional shades may be derived from these colors, but do not introduce unrelated dominant colors.

Use atmospheric lighting, subtle glows, gradients, and controlled contrast.

Avoid excessive gradients everywhere. Visual hierarchy is essential.

## 4. Canvas and Layout Requirements

Create exactly TWO pages.

Each page must have a strict **3:4 aspect ratio** (portrait).

Recommended canvas size: 1080 × 1440 pixels.

Requirements:
- Each page must preserve its 3:4 ratio.
- All important text and visual elements must remain inside safe margins.
- Both pages must look like parts of the same visual identity.
- Each page should work independently as an Instagram post.
- The design must be responsive and look excellent on desktop and mobile.
- Avoid excessive empty space and generic UI components.

If implemented as a web application, provide a convenient way to preview both pages separately.

## 5. PAGE ONE — Brand Introduction

### Objective

Introduce OyanLab and immediately communicate what the brand does.

This page should create curiosity and make the viewer want to explore the second page.

### Main headline

**OyanLab**

### Supporting headline

**Пробуждаем интерес к знаниям.**

English concept: "Awakening curiosity for knowledge."

### Description

Цифровые образовательные материалы нового поколения для преподавателей Казахстана.

### Key visual direction

Create a bold, memorable central visual.

Possible visual concepts:
- A futuristic digital book opening into a luminous 3D space.
- Abstract educational elements transforming into digital particles.
- A glowing geometric symbol combining a book, a play button, and technological shapes.
- A visual metaphor of knowledge awakening through technology.

Do not use childish illustrations, cartoon characters, or generic stock photography.

The central visual should feel sophisticated, artistic, and slightly futuristic.

### Additional elements

Include small, carefully positioned labels:

- DIGITAL EDUCATION
- KAZAKHSTAN
- EST. 2026

Include a subtle visual indication that OyanLab works with teachers.

The brand name must be the strongest typographic element.

## 6. PAGE TWO — Our Services

### Objective

Show teachers exactly what OyanLab can create for them.

This page should communicate the range of services clearly without looking like a boring price list.

### Main headline

**Ваши идеи. Наши технологии.**

### Supporting text

Создаём современные цифровые материалы для уроков по любым школьным предметам.

### Services

Present the following four service categories:

#### 01 — Educational Presentations
Презентации с современной визуализацией, понятной структурой и наглядными иллюстрациями.

#### 02 — Interactive Learning
Интерактивные HTML-задания, тесты, викторины и мини-игры, работающие прямо в браузере.

#### 03 — Educational Videos
Образовательные видеоролики, анимации и визуальные объяснения сложных тем.

#### 04 — Complete Lesson Kits
Комплексные материалы для уроков: презентации, задания, тесты и дополнительные ресурсы.

### Visual direction

Each service should have its own distinctive visual representation.

Use creative mockups and visual metaphors:
- Presentation slides displayed in a floating digital interface.
- Interactive quiz screens with visible answer options.
- A cinematic video frame with a play symbol.
- A collection of educational resources arranged as a digital workspace.

Avoid four identical rectangular cards.

Use asymmetrical layouts, overlapping elements, layered compositions, and varied visual scales.

### Call to action

**Готовы сделать ваши уроки интереснее?**

Напишите нам — обсудим вашу задачу.

**Заказы и консультации: Direct**

## 7. Typography

Use modern, highly legible typography.

Suggested fonts:
- Manrope
- Inter
- Space Grotesk
- Unbounded (for selected display headlines)

Typography should have strong contrast between:
- Large expressive headlines.
- Medium-sized section titles.
- Small technical labels.
- Readable descriptive text.

Avoid using too many different fonts.

## 8. Design Principles

IMPORTANT: The design must be visually distinctive.

Avoid:
- Generic SaaS landing page templates.
- Standard Bootstrap-style cards.
- Excessive rounded rectangles.
- Childish school-themed illustrations.
- Generic stock photos of teachers.
- Overused AI-generated abstract backgrounds without a clear concept.
- Excessive decorative icons.
- Unreadable tiny text.

Prefer:
- Art-directed compositions.
- Strong visual hierarchy.
- Experimental typography.
- 3D-inspired objects and depth.
- Atmospheric lighting.
- Digital interfaces integrated into the composition.
- Carefully controlled gradients.
- Sophisticated use of negative space.

The result should feel like a premium creative studio, not a school presentation template.

## 9. Technical Requirements

Implement the project using clean, maintainable HTML, CSS, and JavaScript.

Requirements:
- Use semantic HTML.
- Use CSS variables for the brand palette.
- Keep page layouts modular.
- Maintain exact 3:4 proportions.
- Ensure mobile responsiveness.
- Optimize images and assets.
- Avoid unnecessary external dependencies.
- Keep text editable in HTML rather than embedding it into images.
- Ensure the final pages render consistently in modern browsers.

If using animations, keep them subtle and purposeful.

The project should be easy to modify later when adding new services, prices, and portfolio examples.

## 10. Final Deliverables

Deliver:
1. A complete working project.
2. Page 1 — OyanLab brand introduction.
3. Page 2 — OyanLab services.
4. Responsive layouts preserving the 3:4 aspect ratio.
5. All source files and required assets.
6. Clear instructions for running the project locally.

## Final Creative Direction

Think like an award-winning digital art director designing a launch campaign for an ambitious EdTech startup.

The first page must make people stop scrolling.

The second page must make teachers understand the value of OyanLab.

**Do not settle for an ordinary design. Make OyanLab visually recognizable.**
